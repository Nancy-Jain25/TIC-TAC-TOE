# Tic Tac Toe 🎮

A simple Tic Tac Toe game built using HTML, CSS, and JavaScript.

## Features
- Two-player gameplay
- Winner announcement
- Reset game functionality
- New game button
- Responsive UI

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Clone the repository
2. Open `index.html` in your browser
